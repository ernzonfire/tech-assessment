# Timed Assessments — Open Only When Ready

These are checkpoints, not reviewers. Finish the related reviewer and exercises first.

## Rules

1. Create a fresh branch or copy of the starter before the timer begins.
2. Read the whole prompt; write assumptions and examples.
3. No AI or copied solutions. Use language/runtime docs only when the prompt permits.
4. Commit or stop when time expires—even if incomplete.
5. Record actual time and what you would do next.
6. Ask Codex to review, score with the rubric, and run a 10-minute defense interview.

## Order

| Assessment | When | Time | Pass target |
|---|---|---:|---:|
| 01 JavaScript Core | After modules 1–3 | 75 min | 70/100 |
| 02 Frontend | After modules 4–5 | 2.5 hr | 70/100 |
| 03 Backend | After modules 6–7 | 2.5 hr | 70/100 |
| 04 Full Stack | After capstone MVP | 4 hr | 75/100 |

## Universal scoring

- Correct behavior and edge cases: 40%
- Readability and decomposition: 20%
- Tests/verification/debugging: 20%
- Communication and trade-offs: 20%

## Score interpretation

- 85–100: strong; add constraints or speed.
- 70–84: pass; review missed edge cases and explanation gaps.
- 50–69: rebuild weak topics, then retake a variant.
- Below 50: return to the relevant reviewer and guided drills.

Do not memorize assessment answers. The post-assessment review should produce general rules and a new variant.
