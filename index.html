Core lesson 01

How JavaScript input becomes output

Follow these in order: receive a value, clean it, decide with conditions, return a result, then display it.

Step 1 · Function

Create, call, and return

A function is reusable behavior. A parameter receives input; an argument is the actual value passed during a call.

function greet(name) {
  return `Hello, ${name}!`;
}

const message = greet("Ana");
// name = parameter
// "Ana" = argument
// message = "Hello, Ana!"
Important: defining the function does not run it. greet("Ana") is the call.
Step 2 · Clean input

Why and when to use `.trim()`

Form input often contains accidental spaces. .trim() returns a cleaned string without changing the original.

const rawName = "   Ana   ";
const cleanName = rawName.trim();

console.log(rawName);   // "   Ana   "
console.log(cleanName); // "Ana"

if (!cleanName) {
  console.log("Name is required");
}
Before calling it: make sure the value is a string, e.g. typeof value === "string".
Step 3 · Conditions

Build an `if / else if / else` flow

Conditions let a function choose one path. Put invalid guards first, then check numeric ranges from highest to lowest.

function getGrade(score) {
  if (!Number.isFinite(score) || score < 0 || score > 100) {
    return "Invalid";
  } else if (score >= 90) {
    return "A";
  } else if (score >= 80) {
    return "B";
  } else if (score >= 75) {
    return "C";
  } else {
    return "F";
  }
}
Order matters: a score of 95 also passes >= 75, so test the highest boundary first.
Step 4 · Output

`return` vs `console.log` vs page display

return gives a value to the caller. console.log is developer-only debugging. textContent shows text to the user.

function greet(name) {
  return `Hello, ${name}!`;
}

const message = greet("Ana");

console.log(message); // DevTools console only

const output = document.querySelector("#output");
output.textContent = message; // visible in the page
No automatic display: returning a value does not place it on the screen—you decide where that value goes.
Functions

Parameters, arguments, and defaults

Parameters are names in the declaration. Arguments are values in the call. Defaults apply when an argument is omitted or undefined.

function calculateTotal(price, quantity = 1) {
  return price * quantity;
}

calculateTotal(100, 3); // 300
calculateTotal(100);    // 100

// price and quantity = parameters
// 100 and 3 = arguments
Functions

Local scope

Variables created inside a function belong to that function. This prevents unrelated code from accidentally changing them.

const taxRate = 0.12; // outer scope

function addTax(price) {
  const tax = price * taxRate; // local scope
  return price + tax;
}

console.log(addTax(100)); // 112
// console.log(tax);      // ReferenceError

Basics

Variables: `const` and `let`

Use const by default. Use let only when the variable must be reassigned.

const name = "Ernie";
let score = 0;
score = score + 1;

// Avoid var in modern code.
Remember: `const` objects can still have their properties changed.
Basics

Values and types

Know what kind of value enters your function before operating on it.

typeof "hello";        // "string"
typeof 42;             // "number"
typeof true;           // "boolean"
typeof undefined;      // "undefined"
typeof null;           // "object" (JS quirk)
Array.isArray([]);     // true
Number.isFinite(42);   // true
Strings

Essential string methods

Strings are immutable: methods return a new string instead of changing the original.

const raw = "  JavaScript Basics  ";
const clean = raw.trim();              // "JavaScript Basics"
clean.toLowerCase();                   // "javascript basics"
clean.toUpperCase();                   // "JAVASCRIPT BASICS"
clean.includes("Script");             // true
clean.slice(0, 10);                    // "JavaScript"
clean.split(" ");                      // ["JavaScript", "Basics"]
clean.replace("Basics", "MERN");      // "JavaScript MERN"
clean.length;                          // 17
Common mistake: write text.trim(), not trim(text), because trim is a string method.
Types

Explicit type conversion

Form values arrive as strings. Convert intentionally, then verify the result before calculating.

String(42);            // "42"
Number("42");          // 42
Number("hello");       // NaN
Boolean(1);           // true
Boolean(0);           // false
parseInt("42px", 10); // 42
parseFloat("19.95");  // 19.95
Number.isNaN(NaN);    // true
Gotcha: Number("") is 0. Check for blank text before conversion when blank is invalid.
Operators

Comparisons and boolean logic

Comparisons create booleans. Logical operators combine or reverse conditions.

age >= 18;                 // greater than or equal
score !== "90";            // strict not equal
quantity <= stock;         // less than or equal
number % 2 === 0;          // even number

isAdult && hasId;          // both must be truthy
isAdmin || isOwner;        // at least one is truthy
!user.active;              // reverse truthiness
Conditions

`switch` and ternary choices

Use switch for exact known values. Use a ternary for one small two-way choice.

switch (status) {
  case "open":
    label = "In progress";
    break;
  case "done":
    label = "Completed";
    break;
  default:
    label = "Unknown";
}

const access = isAdmin ? "Full" : "Limited";
Keep it readable: use regular if/else instead of nesting several ternaries.
Loops

`while`, `break`, and `continue`

A while loop repeats while a condition remains truthy. Break stops; continue skips to the next iteration.

let index = 0;

while (index < values.length) {
  const value = values[index];
  index += 1;

  if (!Number.isFinite(value)) continue;
  if (value === target) break;

  console.log(value);
}
Infinite-loop warning: ensure something changes the condition, such as incrementing index.
Arrays

Add and remove array items

These methods mutate the original array. Know what each method returns.

const queue = ["b", "c"];

queue.push("d");       // add at end
queue.pop();           // remove/return last
queue.unshift("a");    // add at beginning
queue.shift();         // remove/return first
queue.splice(1, 1);    // remove 1 item at index 1

const copied = [...queue]; // non-mutating copy
Arrays

Search, check, sort, and join

Choose a method based on the result you need: boolean, index, side effect, sorted array, or string.

items.includes("apple");             // boolean
items.indexOf("apple");              // index or -1
users.some(user => user.admin);     // any match?
users.every(user => user.active);   // all match?
users.forEach(user => console.log(user.name));

const sorted = [...scores].sort((a, b) => a - b);
const csv = items.join(", ");
Mutation warning: .sort() changes its array, so copy first when order must be preserved.
Objects

Inspect and iterate objects

Convert object properties into arrays when you need array methods or iteration.

const user = { name: "Ana", age: 20 };

Object.keys(user);              // ["name", "age"]
Object.values(user);            // ["Ana", 20]
Object.entries(user);           // [["name", "Ana"], ["age", 20]]
Object.hasOwn(user, "name");    // true

for (const [key, value] of Object.entries(user)) {
  console.log(key, value);
}
Basics

Equality and fallbacks

Prefer strict equality and explicit conversion. Use ?? when zero or blank text are valid.

5 === 5;       // true
5 === "5";     // false
Number("5");   // 5

0 || 10;      // 10
0 ?? 10;      // 0
Falsy: false, 0, "", null, undefined, NaN.
Basics

Conditions and guard clauses

Handle invalid or exceptional cases early to keep the main path readable.

function getLabel(score) {
  if (!Number.isFinite(score)) return "Invalid";
  if (score >= 90) return "Excellent";
  if (score >= 75) return "Passed";
  return "Review again";
}
Basics

Functions and return values

Inputs enter through parameters; useful output leaves through return.

function add(a, b) {
  return a + b;
}

const multiply = (a, b) => a * b;

const result = add(2, 3); // 5
Gotcha: `console.log` prints; it does not return a value.
Basics

Loops

Use for...of when you need each array value; use an indexed loop when the index matters.

for (const item of items) {
  console.log(item);
}

for (let i = 0; i < items.length; i += 1) {
  console.log(i, items[i]);
}
Data

Array essentials

Arrays are ordered collections. Know which operations mutate the original.

const items = ["a", "b"];
items.push("c");              // mutates

const copy = [...items];      // new array
const first = items[0];
const hasA = items.includes("a");
Data

Array method decision guide

map transforms, filter selects, find retrieves one, reduce combines.

const names = users.map(user => user.name);
const active = users.filter(user => user.active);
const ana = users.find(user => user.name === "Ana");
const anyAdmin = users.some(user => user.role === "admin");
const total = prices.reduce((sum, price) => sum + price, 0);
Data

Objects and destructuring

Objects group named properties. Spread creates a shallow copy.

const user = { id: 1, name: "Ana", active: true };
const { name, active } = user;

const updated = { ...user, active: false };
const city = user.address?.city ?? "Unknown";
Data

Set and Map

A Set stores unique values. A Map stores key/value pairs with any key type.

const unique = [...new Set([1, 1, 2])]; // [1, 2]

const usersById = new Map();
usersById.set("u1", { name: "Ana" });
usersById.get("u1");
Data

Closures

A returned function remembers variables from where it was created.

function makeCounter() {
  let count = 0;
  return () => {
    count += 1;
    return count;
  };
}

const next = makeCounter();
Async

Promises and async/await

An async function always returns a promise. await pauses that function, not the whole program.

function delay(ms) {
  return new Promise(resolve => setTimeout(resolve, ms));
}

async function run() {
  await delay(500);
  return "done";
}
Async

Fetch JSON

fetch does not reject for HTTP 404/500. Always check response.ok.

async function loadUsers() {
  const response = await fetch("/api/users");
  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`);
  }
  return response.json();
}
Async

Error handling

Catch where you can recover, translate, add context, or show a useful state.

try {
  const data = await loadUsers();
  render(data);
} catch (error) {
  showError(error.message);
} finally {
  hideLoading();
}
Async

Parallel async work

Start independent operations together. Keep sequential order only when one depends on another.

const [user, tasks] = await Promise.all([
  loadUser(),
  loadTasks(),
]);

const outcomes = await Promise.allSettled(requests);

Select and update the DOM

Events and forms

Handle form submission instead of relying only on button clicks.

form.addEventListener("submit", event => {
  event.preventDefault();
  const data = new FormData(form);
  const title = String(data.get("title") ?? "").trim();
  if (!title) return;

Local browser storage

localStorage stores strings. Serialize structured values and parse defensively.

localStorage.setItem("tasks", JSON.stringify(tasks));

try {
  const tasks = JSON.parse(localStorage.getItem("tasks") ?? "[]");
} catch {
  // Recover from malformed stored data.

React

Component and props

A component describes UI from its read-only props.

function UserCard({ user }) {
  return (
    <article>
      <h2>{user.name}</h2>
      <p>{user.email}</p>
    </article>
  );
}
React

State updates

Use the current-state callback when the next value depends on the previous one.

const [tasks, setTasks] = useState([]);

setTasks(current =>
  current.map(task =>
    task.id === id ? { ...task, done: true } : task
  )
);
React

Effects

Effects synchronize with an external system. Clean up subscriptions and timers.

useEffect(() => {
  const id = setInterval(refresh, 5000);
  return () => clearInterval(id);
}, [refresh]);
Rule: Do not use effects merely to calculate derived values.
Backend

Node HTTP server

Every backend handler receives a request and produces a response.

import http from "node:http";

const server = http.createServer((req, res) => {
  res.writeHead(200, { "content-type": "application/json" });
  res.end(JSON.stringify({ status: "ok" }));
});

server.listen(3000);
Node

npm, modules, and environment

Node runs JavaScript outside the browser. npm manages scripts and packages.

// package.json
{
  "type": "module",

// ES module
import { readFile } from "node:fs/promises";

Express

Express server setup

Express adds routing and middleware on top of Node's HTTP server.

import express from "express";

const app = express();
app.use(express.json());

app.get("/health", (req, res) => {
  res.json({ status: "ok" });
});

app.listen(3000);
Express

Params, query, and body

Route params identify a resource, query values filter, and the body carries submitted data.

app.patch("/tasks/:id", async (req, res) => {
  const id = req.params.id;
  const completed = req.body.completed;
  const includeOwner = req.query.includeOwner === "true";

  // validate → update → respond
});
Backend

REST-style routes

Use predictable resource URLs, HTTP methods, statuses, and error shapes.

GET    /tasks       // list → 200
GET    /tasks/:id   // retrieve → 200 or 404
POST   /tasks       // create → 201
PATCH  /tasks/:id   // update → 200 or 404
DELETE /tasks/:id   // delete → 204 or 404
Backend

Consistent API errors

Validate at the server boundary. Do not leak stack traces or secrets to clients.

{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "title is required",
    "details": { "field": "title" }
  }
}
Express

Error middleware

Forward unexpected errors to one final boundary and return a safe response.

app.use((error, req, res, next) => {
  console.error(error);
  res.status(500).json({
    error: { code: "INTERNAL_ERROR", message: "Something went wrong" }
  });
});
MongoDB

MongoDB CRUD

MongoDB stores BSON-like documents inside collections.

db.tasks.insertOne({ title: "Learn Mongo", done: false });
db.tasks.find({ done: false });
db.tasks.findOne({ _id: ObjectId(id) });
db.tasks.updateOne({ _id: ObjectId(id) }, { $set: { done: true } });
db.tasks.deleteOne({ _id: ObjectId(id) });
MongoDB

Mongoose schema and model

Mongoose adds schemas, validation, models, and query helpers to MongoDB.

import mongoose from "mongoose";

const taskSchema = new mongoose.Schema({
  title: { type: String, required: true, trim: true, maxlength: 120 },
  completed: { type: Boolean, default: false },
  owner: { type: mongoose.Schema.Types.ObjectId, ref: "User", required: true }
}, { timestamps: true });

export const Task = mongoose.model("Task", taskSchema);
MongoDB

Mongoose queries

Queries are async. Filter by the authenticated owner on protected resources.

const task = await Task.create({ title, owner: userId });

const tasks = await Task.find({ owner: userId })
  .sort({ createdAt: -1 })
  .limit(20)
  .lean();

const updated = await Task.findOneAndUpdate(
  { _id: id, owner: userId },
  { $set: changes },
  { new: true, runValidators: true }
);
MongoDB

Indexes

Indexes speed reads but cost storage and write work. Base them on real queries.

// Supports listing one user's tasks newest first.
taskSchema.index({ owner: 1, createdAt: -1 });

// Enforce unique email.
userSchema.index({ email: 1 }, { unique: true });

React calls Express

The React client calls an API route; Express validates, uses Mongoose, and returns JSON.

// React/client
const response = await fetch("/api/tasks");
if (!response.ok) throw new Error("Could not load tasks");
const tasks = await response.json();

// Express/server
app.get("/api/tasks", async (req, res) => {
  const tasks = await Task.find({ owner: req.user.id }).lean();

MERN

Authentication flow

Hash passwords, issue a secure session/token, then authorize each protected resource on the server.

// Login idea
const user = await User.findOne({ email });
const valid = user && await bcrypt.compare(password, user.passwordHash);
if (!valid) return res.status(401).json({ error: "Invalid credentials" });

// Prefer an httpOnly, secure cookie for browser auth.
res.cookie("session", token, { httpOnly: true, secure: true, sameSite: "lax" });

Database

SQL query and join

Use parameterized queries. Join related rows through foreign keys.

SELECT tasks.id, tasks.title, users.email
FROM tasks
JOIN users ON users.id = tasks.owner_id
WHERE tasks.completed = $1
ORDER BY tasks.created_at DESC
LIMIT $2;
Security

Auth and security boundaries

Authentication answers who; authorization checks whether that identity may perform this action.

// Parameterized SQL prevents injection.
db.query("SELECT * FROM users WHERE email = $1", [email]);

// Always authorize resource ownership on the server.
if (task.ownerId !== currentUser.id) {
  return sendError(403, "FORBIDDEN");
}
Testing

Node test runner

Test behavior: arrange input, act, then assert the observable result.

import test from "node:test";

await assert.rejects(() => loadUser("missing"), /not found/i);
