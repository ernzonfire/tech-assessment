How to read any code

Ayaw pagsugod by understanding every symbol. Pangitaa una ang execution start, then answer four questions for every important line.

01

What is the value?

Example: items currently contains ten item objects.

02

What is its type?

Array, object, string, number, boolean, null, or undefined?

03

What enters?

Which arguments are passed into this function call?

04

What returns?

What value leaves the function and where is it stored?

JavaScript

const validItems = searchValidItems(items);
→

Ordinary words

Pass items into searchValidItems, then store its returned array in validItems.
Parameter vs argument: array is the receiving parameter in the function declaration. items is the actual argument in the call.

Quick check

Inside .find(item => ...), what is item?

JavaScript quirk: typeof null is "object". For valid finite numeric ratings, Number.isFinite(item.rating) is safer than a truthy check because rating 0 is valid.

Lesson 04

Three array methods, three jobs

Many → fewer

.filter()

items.filter((item) =>
  Number.isFinite(item.rating)
);

Callback returns a boolean for every item. All passing items go into a new array.

Many → one

.find()

items.find((item) =>
  item.name === itemName
);

Stops at the first match. Returns one object or undefined.

Same items → new order

.sort()

[...items].sort((a, b) =>
  b.rating - a.rating
);

b - a is descending. Copy first because .sort() mutates.

Quick check

Which method returns every item that passes a condition?

Lesson 05 · Your assessment

Hunt the bugs deliberately

This code contains multiple independent bugs. Fixing one may reveal the next. That does not mean your first fix failed.

function searchValidItems(array) {
  return array.filter(
    item => typeof item.rating === "string"
  );
}

function sortByRating(array) {
  return array.sort(
    (a, b) => b.rating - a.rating
  );
}

function getRating(itemName, array) {
  const item = array.find(
    item => itemName === item
  );
  return item ? item.rating : null;
}

function main() {
  const item = [ /* item objects */ ];

  const validItems = searchValidItems(items);
  const sortedItems = sortByRating();
  const ratingOfItemA = getRating(
    "Item A", validItems
  );
}
Bug 01Which ratings are valid?

The data uses numbers, not strings. Use Number.isFinite(item.rating) so 0 stays valid while null, strings, NaN, and infinities are removed.

Bug 02Which variable actually exists?

const item is declared, but items is used later. Variable names must match exactly. For a collection, declare const items.

Bug 03What input does sorting receive?

sortByRating expects an array parameter, but the call passes nothing. Call sortByRating(validItems).

Bug 04String compared with object?

itemName is a string while item is an object. Compare item.name === itemName.

Bug 05Why did validItems change order?

.sort() mutates its array. Use [...array].sort(...) when the valid and sorted arrays should remain separate.

Possible syntax bugWere Markdown fences pasted?

If literal ```javascript fences are inside the source file, remove them. They format Markdown; they are not JavaScript syntax.

Lesson 06

Debug in this order

  1. 1
    Run before editing

    Capture the first exact error or failed test. Do not fix five guesses at once.

  2. 2
    Fix syntax errors

    Missing brackets, parentheses, quotes, or pasted Markdown can stop parsing.

  3. 3
    Fix runtime errors

    Check undefined variable names, missing arguments, and unsafe property access.

  4. 4
    Fix logic errors

    Trace one input. Compare actual types, properties, conditions, and returned values.

  5. 5
    Check boundaries and side effects

    Test zero, null, missing data, duplicates, empty arrays, and mutation.

  6. 6
    Explain the root cause

    Say: expected, actual, cause, smallest fix. If you cannot explain it, trace again.
